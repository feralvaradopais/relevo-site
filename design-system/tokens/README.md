# Design tokens

`tokens.css` is the canonical extracted set of approved Relevo Studio Design
System v5 “Festa” values. Its declarations were copied without changing values.

The handoff's `base.css` and literal keyframes are kept under
[`../reference/claude-design-v5/`](../reference/claude-design-v5/) because they
contain reference implementation choices, including Google Fonts loading and a
CSS scroll-timeline assumption. They must not be treated as an approved
production architecture.

Do not add, rename, or change tokens without explicit design approval.
