# Systems Atlas illustration grammar
Original vector studies, not production assets. A shared grid, thin strokes, modular nodes, restrained organic geometry, figure numbering and annotations. Use a consistent viewBox (e.g. 320×240), normalized stroke scale and bounded forms, with separate accessible text when diagram conveys information. Do not use color alone. Define parameters (count, spacing, curvature, phase, seed) and reproducible deterministic output. No copying reference artwork.
Six motifs: Integration (paths converge), Organization (nested forms resolve), Intelligence (orbital structure with focal point), Execution (bounded branching to actions), Verification (inspection and confirmed state), Evolution (structured transformation across stages). Each motif should represent a specific meaning, not arbitrary network decoration. Hero FIG.01: Input → Context → Intelligence → Action with human authorization/oversight; diagram conceptual, not a claim of existing platform.
Start with 4–6 SVG studies and one hero composition; validate readability on mobile and print before expanding. Provide static equivalents. Do not claim a finished library until assets exist.
