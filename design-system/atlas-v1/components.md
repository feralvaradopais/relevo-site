# Components
Prototype: primary forest button with white label and arrow, secondary outlined, text link with visible underline; minimum 44px target as design goal. Focus visible with offset high-contrast outline, hover and disabled clearly distinct. Header editorial rule and restrained navigation. Solution modules use flat surfaces, figure number, heading, concise explanation, explicit action. Inputs have persistent labels, strong boundaries, focus, error and help text; no placeholder-only labels. Status includes text. Prefer semantic elements, keyboard access and accessible names; no fake controls in production. No default shadows or pill-heavy UI. Review actual contrast, target sizes and states before implementation.
