# Typography — selected family
Fernando chose Söhne + Söhne Mono on 2026-11-27 after the typography lab. This supersedes previous candidates; Geist/Geist Mono remain practical fallback, not the chosen identity.
Internal lockup study uses real Klim test fonts: Söhne Halbfett for relevo, Buch for studio; proposed Buch body, Kräftig navigation/subheads, Halbfett or Dreiviertelfett display, Mono Buch annotations. Exact weights, tracking and optical spacing remain subject to QA. Brand Book v1.3 records the choice with rasterized internal samples. Test fonts lack accents, ñ and other glyphs and OpenType features per archive readme; do not use them to validate full Spanish production copy. Never commit, distribute or deploy trial font files or trial-derived production wordmarks. Obtain appropriate commercial licenses and verify full character set before production. No license purchase approved.
Prototype fallback Geist/Geist Mono or system-ui if unavailable. Proposed desktop H1 72–80px / 1.02 / -0.045em, mobile 42–48px / 1.05; H2 48/34, H3 28/24, body 18/16 line-height 1.55, annotations 11–12px line-height 1.5. Values are studies; adapt to real type metrics and responsive legibility. Check Spanish glyphs, wrapping, zoom and font loading.
