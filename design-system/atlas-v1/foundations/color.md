# Color
Exploratory palette: Paper #F3F2EB, Mist #E3E7DB, Sage #B0BFA3, Moss #647D5D, Forest #263E30, Ink #19271F. Paper is the dominant surface; Mist is alternate; Forest is primary action; Ink is body; Moss/Sage are diagrams and accents, not default small text. Use #52664F for secondary text and #677960 for meaningful control borders. Decorative hairlines can use #B0BFA3; never use decorative borders as sole control boundary. Error #8B302D and warning #735016 are prototype semantic colors, not brand colors. Status needs text/icon in addition to hue. Contrast targets WCAG AA: 4.5:1 normal text, 3:1 large text and meaningful nontext UI; validate actual backgrounds and states. White on Forest is candidate CTA. No gradients or shadows by default.
