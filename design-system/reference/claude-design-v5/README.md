# Claude Design v5 “Festa” reference

Preserved inspection material from the approved Claude Design handoff:

- `Relevo Studio Design System v5 Festa.dc.html` — editable visual source.
- `support.js` — generated Claude Design runtime required to open the source.
- `base.css` — extracted reset/font-loading reference.
- `motion.css` — extracted literal keyframe reference.

Open the `.dc.html` file directly in a browser with `support.js` in this
directory. These files are historical/visual reference, not production website
source. Do not edit them to resolve handoff inconsistencies.

The handoff's separate 584 KB standalone bundled HTML was intentionally not
copied. It repackages the same design and generated runtime, while the editable
source retained here is the handoff's stated definitive visual reference.
